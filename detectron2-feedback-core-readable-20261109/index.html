INTERPRETATION

这份结果的适用边界

  • 这是核心范围重写，不是完整 Detectron2 的替代品。通过测试不证明所有可能输入上的语义等价。
  • 固定 checkpoint 使用原版随机权重，验证格式和数值兼容；没有据此声称 COCO 精度或预训练模型质量。
  • GPU 结果覆盖选定核心探针，不代表完整分布式训练或全部 CUDA 算子。两侧执行时间含导入与缓存差异，不作为性能对比基准。
  • 源码 tokens 是体积指标。未开展真实开发任务评估，不能把体积缩减直接解释为认知负担下降。
