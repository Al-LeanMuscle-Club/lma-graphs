    Method and limits

    • Both versions use tiktoken 0.12.0 / cl100k_base, independently per file.
    • Unchanged original tests, documentation and binary assets are excluded under the frozen policy; modified text remains counted.
    • The frozen classifier counts the unchanged notebook fixture and its nbval configuration as 4,291 configuration tokens in both versions.
    • Reused static knowledge and check definitions refer to the identical upstream commit. No previous candidate implementation or passing results were reused.
    • The author used a fresh source-free workspace. This shared-host workflow boundary is not OS-enforced isolation.
    • Task inputs were corrected before this run to explain withheld independent checks; acceptance checks and fixtures were unchanged.
    • Task variants use one repetition. This is exploratory cost evidence, not a statistical estimate of general cognitive burden.
    • Real-task modifications run in disposable repository copies; their patches are not merged into the delivered implementation.
    • Logged CLI model usage excludes this coordinating conversation and preparation. Cached input is a subset of input, not added again. Interrupted sessions without final usage receipts are counted as unmetered calls; their reported role usage is a known subtotal, not a complete total. Their durations are bounded by confirmed cleanup.
    • Additional original-versus-candidate CLI checks exposed help/version output going to stderr instead of stdout. The owner delivery gate was strengthened and repair resumed, while main, the frozen 26 check groups and task contracts stayed unchanged.
    • The task assessment of the earlier candidate was stopped because that candidate failed the supplemental CLI behavior check. Its completed solver usage is included in experiment totals, but that candidate is not used as the final candidate comparison.
    • Workflow duration excludes preparation and publication. Role durations may overlap and should not be summed as wall time.
    • Finite checks do not establish complete semantic equivalence.
    • Tk desktop interaction lacks a display; matplotlib uses Agg and notebook checks exercise widget state.
    • Slack, Discord and Telegram transports are mocked; real service delivery is not exercised.
    • External download/archive demos are parsed, not executed end-to-end. Windows and macOS are not exercised.
    • Notebook cells run with nbval-lax; historical stored output prose is not compared.
