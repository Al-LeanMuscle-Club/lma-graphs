How this graph was prepared

The complete Graphify graph was imported, then reviewed and grouped by functional behavior. Graphify communities are candidate groupings, not verified feature boundaries. The 89 modules and their 367 details were authored by the reviewing agents using graph evidence and static source inspection.

Graphify processed 726 code inputs. 133 configuration or data-style inputs yielded no symbols, and 92 non-code documents and assets were skipped by code-only analysis. The separate source inventory and reviewed mappings cover all 452 files counted by the harness; tests and non-production material use a different counting scope. Coverage of source files does not establish behavioral completeness. Shared files count once. Solid hierarchy, required dependencies and extracted or inferred relationships are shown separately.
