What the evidence establishes

The report records observed behavior for declared checks and environments. It does not prove equivalence for every possible input, platform or third-party service.

  • On this Linux ARM64 host, upstream Python tests exercise the core meter, CLI, asynchronous iteration, pandas, monitoring and locks, contrib helpers, concurrent execution, logging, notebook, Rich, Dask and Keras integrations.
  • Python 3.14 exercises subinterpreters and modern itertools behavior. Python 3.8 receives supplementary syntax, import and basic iteration checks.
  • Fresh non-editable installation checks package resources and both module and console entry points. A second installation check clones the actual published branch and builds it without an overridden SCM version.
  • All 19 original notebook test cells execute successfully with their assertions unchanged; stored output prose is not compared (nbval-lax). Matplotlib and notebook smoke checks additionally create objects and update progress state. GUI interaction and visual correctness are not established. Native Tk desktop rendering is not verified without a display; native Windows and macOS behavior was not executed.
  • Discord, Slack and Telegram API interactions use mocks; live external-service behavior is not verified. Demo and release tooling inspection is not proof that every external CI, download or publishing workflow succeeds.
  • A single representative modification-task assessment is exploratory. This run could not establish a valid baseline, so it provides no comparative task-cost result. The incomplete assessment is reported explicitly.
