    06 / INTERPRETATION

    Choose the trade-off, not one score.

    These are observational experiments with different objectives and procedures, not a controlled trial of six algorithms.

    What a controlled follow-up would need

    Use the same original commit, selected functionality, public API obligations, environment, test inventory, model/reasoning settings, source access policy, repair budget, and stopping rule. Capture parent and child model usage plus all cancelled calls. Run the same pretrained checkpoints, representative training/export/integration checks, and matched performance workloads on every final candidate. Evaluate documentation and developer tasks separately from code size.
